def check(self, gray):
    small = cv2.resize(gray, (480, 270))
    blur = cv2.Laplacian(small, cv2.CV_64F)[self.valid].var()
    self.blur_ref = blur if self.blur_ref is None else 0.999 * self.blur_ref + 0.001 * blur
    frozen = self.prev is not None and cv2.absdiff(small, self.prev)[self.valid].mean() < 0.5
    self.frozen_cnt = self.frozen_cnt + 1 if frozen else 0
    self.prev = small
    return {"ok": self.frozen_cnt < 3 * FPS,             # 약 3초
            "blur_ratio": blur / (self.blur_ref + 1e-6),
            "mean_v": float(small[self.valid].mean())}

NCNN탈락

▸ GPU 없는 저가형 ARM 보드라면 적합
OpenVINO탈락

인텔 CPU·iGPU·NPU용이라 NVIDIA GPU를 지원하지 않습니다. Orin NX에서는 ARM CPU만 쓸 수 있어 GPU가 놀게 됩니다.

▸ 엣지를 인텔 산업용 PC로 바꾸면 재검토
LiteRT (TFLite)탈락

Jetson에서는 GPU 델리게이트 활용이 제한적이고, PyTorch → ONNX → TF → .tflite로 변환 단계가 늘어 분할 헤드 같은 연산이 깨질 위험이 큽니다.
